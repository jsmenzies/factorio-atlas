# data/

| Path | What | Source |
|---|---|---|
| `game/game-data-2.0.55.json` | What the analyzer loads: recipes, crafting machines, belts, modules, beacons, planets and the icon sprite-sheet layout from the KirkMcDonald calculator's 2.0.55 Space Age data, slimmed down, plus every prototype name, entity size, surface condition and rename migration from a regex scan of Wube's Lua sources. Generated by `bun run game-data <checkout>`; don't edit by hand | KirkMcDonald 2.0.55 + [wube/factorio-data](https://github.com/wube/factorio-data) tag 2.0.55 |

## Not in the repository

These are gitignored and exist only on the machine that made them:

| Path | What |
|---|---|
| `raw/factorioprints/<id>.json` | Sanitised factorioprints records saved by `bun run ingest`, read by `bun run ingest --from-disk` and `bun run render`. `favorites` and `image.deletehash` are removed by `sanitizeRaw` in `src/lib/server/pipeline/pipeline.ts` |
| `source/` | Local id lists |
| `renders/` | Output of `bun run render` |

Prints belong to their authors. To get prints locally, use `bun run backfill --stage local
--limit N` or `bun run ingest <id>`, which read the GitHub mirror
[motlin/factorio-blueprint-firebase-cdn](https://github.com/motlin/factorio-blueprint-firebase-cdn).
Never fetch in bulk by looping over Firebase, whose bandwidth is billed to factorioprints.com's
maintainer.

Tests that need real prints download them from the mirror at a pinned commit into
`.cache/fixtures/` (`src/lib/server/fixtures.ts`).
